# 技术架构详解

本文档详细解释 v3「真迹」引擎的技术原理。

---

## 一、整体管线

v3 引擎的渲染管线分为 6 个阶段：

```
文本 → 排版 → 骨架查找 → 轨迹合成 → 墨迹沉积 → 纸面合成 → 成像仿真 → 输出
```

每个阶段都有明确的输入输出契约，且全部使用**物理单位**（毫米、DPI），像素只在最后光栅化阶段出现。

---

## 二、排版阶段

### 2.1 折行算法

使用贪心折行 + 中文标点避头避尾规则。

- **避头尾字符集**：行尾不能出现 `([{·` 等，行首不能出现 `,.;:!?)]}` 等
- **首行缩进**：按 `paragraph_indent` 字符数缩进
- **手动分页**：`---` 单独一行触发分页
- **右对齐**：`>>>` 前缀的行右对齐

### 2.2 基线漂移

真人写不出完全等距的行。基线位置使用 **AR(1) 自回归过程**：

```
y[i] = y[i-1] + ρ * (y[i-1] - y[i-2]) + ε
```

其中 ρ 是自相关系数（约 0.3~0.5），ε 是高斯噪声。这使得行距有"记忆"，不会像独立随机那样跳来跳去。

## 三、骨架阶段

### 3.1 数据来源

9,574 个汉字，每笔 24 个采样点，总共 112,617 笔。
数据来自 [hanzi-writer](https://github.com/chanind/hanzi-writer)，基于文鼎公众授权字型。

### 3.2 笔型分类

11 种笔型，每种有独立的宽度剖面：

| 笔型 | 特点 |
|---|---|
| 横 | 两头粗中间细，起笔顿收笔顿 |
| 垂露竖 | 起笔顿，收笔顿（竖下） |
| 悬针竖 | 起笔顿，收笔出锋（尖） |
| 撇 | 从粗到细，收尖 |
| 捺 | 中间鼓，两头尖 |
| 点 | 橄榄形，中间最粗 |
| 提 | 斜向，起笔顿收笔尖 |
| 折 | 转角圆化 |
| 钩 | 钩部有独立增益 |
| 折钩 | 折+钩组合 |
| 弯 | 弧形笔画 |

## 四、轨迹合成阶段（最核心）

### 4.1 四层变形机制

每个汉字的书写轨迹经过四层变形：

**第一层：结构变形**
- 左右/上下结构的部件比例偏置
- 中宫松紧（靠近字心的部分收放）
- 字面宽高比修正
- 横画上扬（横向笔画绕起笔点抬起）
- 整字倾斜（切变变换）

**第二层：MLS 弹性形变**
- 4×4 网格控制点，每个点加独立随机扰动
- 用 **Moving Least Squares 相似变换**（复数域闭式解 `f(z) = a·z + b`）
- 边界控制点扰动减半，防止整字轮廓塌陷
- 效果：每次出现的字有独立的弹性形变，"这一次写得瘦一点、右下角塌一点"，但仍然是合法的字

**第三层：动力学模型**
这是最核心的部分，包含三个物理模型：

#### (a) Σ-Lognormal 速度剖面

```
v(t) = Σ v_i · exp(-(ln(t - t_i) - μ_i)² / (2σ_i²))
```

按曲率极大值把笔画切成多段子运动，每段产生一条右偏的对数正态钟形速度曲线。
这是 **Plamondon 快速人体运动理论**的标准结论 —— 人体快速运动的速度剖面天然符合对数正态分布。

#### (b) 2/3 幂律（速度-曲率关系）

```
v ∝ κ^(-1/3)
```

人体运动学经典结论：曲率越大，速度越低。
直接导致：转折处自然加粗（因为慢笔压力大、墨迹厚），收笔自然出锋。

#### (c) 压力模型

- 速度反相关：慢笔压力大 → 墨迹粗
- 曲率正相关：转折处压重
- 提按低频调制：正弦波模拟书写节奏
- OU 过程噪声：Ornstein-Uhlenbeck 过程，比纯白噪声更符合生理

**第四层：牵丝连笔**

- 笔画间距 < 阈值且随机命中时生成连笔
- 用前一笔收笔方向和后一笔起笔方向做三阶贝塞尔曲线
- 中段最细，压力只有主笔的 16~45%
- 楷书 → 行楷 → 行书 三级梯度可控

## 五、墨迹沉积阶段

### 5.1 笔尖足迹

把笔画重采样到亚像素间距，每个采样点是一个笔尖椭圆足迹。

**半径公式（Hertz 接触）**：

```
radius = nib_radius * width_scale * (1 + gain * pressure)^(1/3) * (1 - speed_loss)
```

压力与接触半径的 1/3 次方成正比 —— 这是弹性接触的经典结论。

用 `np.bincount` 做散射累加，比 `np.add.at` 快一个量级。

### 5.2 流量模型

```
flow = base_flow * (1 + pressure_flow_gain * pressure) * (1 - starvation) * (1 + pooling)
```

- **断墨模型（starvation）**：有限储墨 + 恢复率 + 速度相关消耗 → 产生飞白（笔画中突然缺墨的效果）
- **堆积模型（pooling）**：慢笔 + 转折处墨水堆积变粗

### 5.3 后处理

- **纸纤维洇散**：高斯模糊，总墨量守恒（35% 原图 + 65% 模糊）
- **咖啡环效应**：干燥时墨向边界迁移，边缘比中心深
- **超采样降采样**：面积平均，保证分辨率一致性

### 5.4 Beer-Lambert 合成

```
optical = mass * absorb_rgb * density_gain
transmittance = exp(-optical)
result = paper * transmittance + ink_linear * (1 - transmittance)
```

分通道吸收，薄墨处向墨水色相偏移（蓝黑墨薄处偏蓝）。
不是简单的灰阶填充，这是肉眼可感的真实细节。

## 六、纸面阶段

### 6.1 纸张生成

- **Value Noise** 生成纤维纹理
- 低频色斑模拟纸张不均匀
- 横线 / 方格按物理间距绘制

### 6.2 吸水率图

空间变化的洇散系数，模拟纸张不同位置的纤维密度差异。

---

## 七、成像仿真阶段

模拟"拍照"的全过程：

1. **光照场**：中心亮四周暗的二次曲面
2. **暗角（Vignette）**：镜头边缘进光量减少
3. **纸张微曲**：微弱的柱面弯曲
4. **镜头散焦**：高斯模糊模拟景深
5. **色差**：RGB 通道微小错位
6. **传感器噪声**：
   - 光子散粒噪声（Poisson）：光越强噪声越大
   - 读出噪声（Gaussian）：电路噪声
7. **ISP 锐化**：模拟相机的锐化处理
8. **JPEG 压缩**：DCT 压缩伪影

## 八、真实度度量

`metrics/` 模块提供可量化的真实度指标：

| 指标 | 说明 | 真人中位 |
|---|---|---|
| `stroke_width_ks` | 笔画宽度分布 KS 距离 | 0.165 |
| `density_hist_emd` | 墨迹密度直方图 EMD 距离 | 0.092 |
| `baseline_psd_slope` | 基线功率谱斜率 | 0.517 |
| `glyph_selfvar` | 同字自变异系数 | — |
| `ink_paper_noise_match` | 纸墨噪声匹配度 | 0.869 |
| `radial_psd_match` | 径向功率谱匹配度 | 0.993 |

判别器（`discriminator.py`）可以输出逐特征的 AUC 值，量化"真假"的可分性。

## 九、为什么不用字体 + 抖动？

| 维度 | 字体+抖动 | v3 引擎 |
|---|---|---|
| 字形 | 同一个字永远同一个形状 | 每个实例有独立形变 |
| 笔画粗细 | 全局一致 | 速度+压力+曲率动态决定 |
| 交叉处 | alpha 混合，和别处一样黑 | 墨量累加，自然更黑 |
| 起收笔 | 字体决定，没有提按 | 物理模型自动产生提按 |
| 长文变化 | 逐字独立随机，像噪声 | AR(1) 漂移+疲劳，像真人 |
| 墨色 | 纯色填充 | Beer-Lambert 分通道吸收 |
| 纸张 | 贴一张背景图 | 纤维+洇散+成像全仿真 |

简单说：字体+抖动是"同一个字挪来挪去"，v3 是"每次重新写一遍"。

## 十、性能优化要点

- `np.bincount` 散射累加（比 `np.add.at` 快 10x）
- 可分离高斯模糊（自实现，比 scipy 快）
- sRGB↔线性 LUT 查表（替代整页幂运算）
- 变体缓存：同字同风格复用渲染结果
- 超采样精度分级：preview 1x，hd 2x，high 3x
- PNG 压缩级别 6→1（整页编码 839ms→223ms，体积仅 +15%）
